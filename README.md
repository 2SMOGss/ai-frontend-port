# Robert Chich — High-Performance Portfolio

A premium, immersive developer portfolio built with a focus on motion design, 3D interactivity, and cloud security aesthetics. This project features a unique "materialization" sequence where chaotic particles coalesce into an interactive glassmorphic interface.

![Portfolio Preview](public/branded-icon.png)

## ✨ Key Features

- **The Materializer**: A custom Three.js particle system that transitions from high-entropy chaos into a structured 3D interface upon page load.
- **Glassmorphic Terminal**: A sleek, translucent "System Terminal" chat modal that utilizes backdrop filters and scanline effects for a professional cybersecurity look.
- **Dynamic Node Network**: Floating background repository nodes connected by animated SVG lines that track the main CTA button.
- **3D Tilt Interaction**: An interactive CTA card with real-time mouse-tracking tilt effects and dynamic glare.
- **Ambient Atmosphere**: Layered background effects including animated radial glows, a noise texture overlay, and a cyber-grid vignette.
- **Full Responsiveness**: Tailored layouts for mobile, tablet, and desktop ensuring a premium experience on any device.
- **Performance Optimized**: Built with layout-thrashing prevention, GPU-accelerated blur filters, and cached DOM measurements.

## 🚀 Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Vanilla CSS3 (Custom Design System)
- **3D Engine**: [Three.js](https://threejs.org/)
- **Animation**: [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- **Build Tool**: [Vite](https://vitejs.dev/)

## 🛠️ Setup & Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/2SMOGss/ai-frontend-port.git
    cd ai-frontend-port
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
